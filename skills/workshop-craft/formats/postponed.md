# postponed.md

What the work found or decided and left for later, so it is not lost when the task ends. Its items can be the
start of a later workshop-craft.

```
# Postponed

- <what it is>. Kind: <problem found, not fixed | follow-up task | deferred feature or decision>.
  Found in: <the scope | pipeline N, Category, iteration M>.
  Source: <file:line | "user said">, <date>.
```

- Written in the turn it is found; the report mentions it in one line.
- An item taken into the task moves to the scope or a pipeline and is deleted here.
- When the task ends, the list is shown to the user to decide on each item.
- The scope's Out of scope keeps the decision that something is not in the task; the work item lives here.
