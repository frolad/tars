# 01-blockers.md

Only what must be resolved before the scope can be finished. After workshop-craft it is normally absent. A blocker that
concerns one pipeline goes into that pipeline's `iterations.md` instead.

```
# Blockers of the scope

- Blocker 1: <question>.
  Blocks: <scope section, or whether a pipeline exists>.
  Who can answer: <the user | the agent, by looking up <what>>.
  Status: open.
```

- A resolved blocker becomes a line in `02-scope.md` or `00-knowledge.md` and is deleted here, so the file
  holds only what is still open. When the last one is resolved, the file is deleted.
